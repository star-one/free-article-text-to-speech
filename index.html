Why In-Place DOM Highlighting Matters for Web Articles

By Simon Gray • November 22, 2026

Audio Edition:

Many browser-based text-to-speech demonstrations strip away an article’s rich HTML formatting and dump plain text into a preformatted block while reading. That approach breaks multi-column layouts, removes links, and interrupts the visual hierarchy of the page.

Instead, this lightweight script uses a native TreeWalker and the Range API to map spoken character offsets directly onto live text nodes inside the article container. Each word is wrapped in a <mark> element in place and cleanly restored as playback advances.

Adaptive Controls

When idle, only the Read Aloud button is displayed so the reading interface stays uncluttered. Once playback begins, Pause, Stop, a narrator Voice selector, and a Speed selector appear automatically—and changing voice or speed mid-sentence resumes seamlessly from the current word.
